Cómo funciona

Lo determinista lo calcula Rust; la interpretación la hace tu agente; adoc orquesta y valida.

  1. 1

    adoc scan

    Inventario sin IA: lenguajes, módulos, tests, CI, historial git y OpenSpec. Respeta .gitignore y excluye secretos.

  2. 2

    adoc plan

    Divide el trabajo en tareas acotadas según el tamaño del proyecto: pocas tareas en uno pequeño, más en uno grande.

  3. 3

    adoc inspect

    Tu agente ejecuta cada tarea. Solo se marca hecha si produjo lo pedido con evidencias válidas.

  4. 4

    adoc preview

    Sitio con dashboard: estado, hallazgos, preguntas para el equipo y FAQ. O un reporte HTML único.

  5. 5

    adoc sync

    Cuando el código cambia, marca las notas afectadas como desactualizadas y reabre solo esas tareas.

Instalar

Un comando según tu sistema: descarga el binario de tu plataforma, verifica su SHA-256 y lo deja en el PATH. No necesitas Rust. Node 18+ solo para el sitio VitePress y la extensión.

Terminal

$ curl -fsSL https://tu-sitio/download/install.sh | sh

o descarga el binario

Apple Silicon (M1–M4) Intel

Descargado desde el navegador, macOS lo marca en cuarentena: xattr -d com.apple.quarantine adoc archeology-doc y muévelos a ~/.local/bin. Con el comando de terminal no hace falta.

Terminal

$ curl -fsSL https://tu-sitio/download/install.sh | sh

o descarga el binario

x86_64 ARM64

Binarios para glibc 2.28 o superior (Debian 10, Ubuntu 18.10, RHEL 8 y posteriores).

PowerShell

> irm https://tu-sitio/download/install.ps1 | iex

o descarga el binario

Windows x64 (.zip)

El instalador lo deja en %LOCALAPPDATA%\Programs\archeology-doc\bin y lo añade a tu PATH, sin permisos de administrador. En Windows ARM64 funciona con la emulación x64.

# Necesita Rust (rustup.rs). Instala `adoc` en ~/.cargo/bin
git clone https://github.com/jsoncr/archeology-doc.git

WEBSITE/installers/install.sh

Extras

# Con VitePress compartido y la extensión de VS Code
curl -fsSL https://tu-sitio/download/install.sh | sh -s -- --with-vitepress --with-vscode

# Verifica requisitos: git, Node, VitePress, OpenSpec y agentes
adoc doctor

Se instalan dos binarios equivalentes: adoc (corto) y archeology-doc. Para desinstalar: adoc uninstall (con --purge borra también ~/.archeology-doc; los archivos de tus proyectos no se tocan).

Primeros pasos

En la carpeta de tu proyecto:

cd mi-proyecto

adoc init                 # config + estructura
adoc agent use claude     # o devin, codex, gemini…
adoc scan                 # inventario determinista
adoc plan                 # tareas según el tamaño
adoc inspect              # el agente documenta
adoc preview              # ver el resultado

Día a día

adoc reviewProgreso, hallazgos, funcionalidades sin tests
adoc inspect --resumeReintenta tareas fallidas o interrumpidas
adoc task answer T-014 "…"Responde a un agente que preguntó
adoc task run T-014 -iSesión interactiva con el agente
adoc ask "¿…?"Pregunta sobre el proyecto → FAQ
adoc syncDetecta cambios y marca notas desactualizadas
adoc checkValidaciones para CI
adoc reportReporte HTML único para compartir
adoc projects listTodos tus proyectos y su progreso

Extensión para VS Code

Todo lo generado, a la vista mientras programas. Funciona también en Cursor, Windsurf y Devin Desktop.

  • Tareas por estado con botón ▶ para ejecutarlas
  • Hallazgos con salto a la línea de evidencia
  • Grafo del conocimiento, como en Obsidian
  • Preguntas del agente y del equipo, y FAQ
  • Marcas en el editor en el código citado
  • Progreso y agente activo en la barra de estado

npm install

Qué queda en tu proyecto

Principios

  • Evidencia ante todo: cada afirmación cita ruta:línea
  • No destructivo: nunca modifica tu código; respeta tus ediciones
  • Local-first: nada sale de tu máquina salvo lo que envíe tu agente
  • Incremental: tareas pequeñas, reanudables, por módulos
  • Estándares: Markdown, OpenSpec, AGENTS.md, Obsidian y VitePress
